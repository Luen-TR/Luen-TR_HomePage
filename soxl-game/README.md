# SOXL HEARTBEAT

SOXLの日足と連動するトレード×恋愛ゲーム。既存ホームページの `soxl-game/` に独立して配置。ホームページ本体とOGPは維持。

## プレイ

- 2010年3月11日〜2026年9月8日、4,149営業日の実際のOHLCと出来高。
- 開始日はその日の引け後。初期資金10,000USD、30/60/120営業日または収録最終日まで。
- 現金または保有株の25/50/100%で買い・売りを予約し、翌営業日の始値で約定。一度に1件、上書き・取消可。
- 約定代金の0.1%が売買手数料。端株あり。ショート、借入、分配金、税、為替、スリッページは対象外。
- 総資産はその日の終値で評価。エンディングで強制売却はしない。
- SOXLそのものの価格を利用し、3倍を重ねて適用しない。
- ローソク足は当日まで。20日平均も過去の終値のみを使用。注文時に次の始値や将来のチャートを出さない。
- 1日1回の会話で親密度・信頼が変わる。株価に連動する機嫌とは別の指標。
- デートは5営業日後。カフェ35USD、散歩無料、ゲームセンター50USD。会話後に支払う。現金不足なら無料の散歩に変更。
- デート当日の前日比・値幅で場面と選択肢が変わる。イベント中は日を進めず、最後の日のデートも解決してから結末へ。
- 5つのエンディング。ブラウザのlocalStorageに自動保存。データの識別子と保存形式を照合し、不正な記録は読み込まない。

## データ

Yahoo Financeの公開日足チャートレスポンスを `import_history.py` で検証し `data/soxl-daily.json` に収録。補間・架空の足は作らない。

- 元データ： https://finance.yahoo.com/quote/SOXL/history/
- 調整：株式分割調整済みOHLC、分配金調整なし。`adjclose`は不使用。
- 株式分割：2015-05-20（4:1）、2021-03-02（15:1）。価格単位に反映済みのため保有株を再分割しない。
- 取得日時、元レスポンスSHA256、最初・最後の日付、件数、除外日をJSONメタデータに保存。
- 米国東部時間の当日16:15前の足および未来の日付は除外。9月末までの未来データは存在しないため入れない。
- 相場メモは四本値の説明。一部の時期に公式発表を出典付きで表示。特定日の値動きの原因を断定しない。決算の引け後公表は翌営業日から表示。

更新：公開チャートレスポンスを取得した後 `python3 soxl-game/import_history.py /absolute/path/response.json`。データが変わると保存識別子が変わるため、既存プレイの継続互換性は別途設計する。

## 構成・検証

- `engine.mjs`：注文、会計、営業日進行、関係、デート、結末、セーブ検証。
- `story.mjs`：実際の日足を読んで会話・デート・相場メモを選択。
- `chart.mjs`：Canvasローソク足、出来高、20日平均、売買マーカー。表とキーボード操作も提供。
- `game.js`：画面、入力、モーダル、読み込み、自動保存。
- サーバーへの取引送信やプレイヤー情報収集はなし。データは同梱。

`node --test soxl-game/tests/engine.test.mjs`

実データの整合性、翌始値での約定・手数料・部分売却、将来参照の禁止、デートの気分分岐・費用・最終日進行、セーブ復元、全期間の通しシミュレーションを検証。

`python3 build.py --origin https://luen-homepage-preview.luen-tr.chatgpt.site`

## ノベルゲーム版（2026-09-09）

原作：ユーザー提供「SOXLちゃんは今日も三倍」。タイトル・人物関係・場面・「眠れる大きさ」を軸に脚色。

- 一枚絵のある部屋やデート先を主画面にし、売買画面を「相場と売買」から開く構成へ。
- `novel.mjs` は場面ごとのページ、既読の章、会話ログ、解放済みCG、途中ページを管理。ページ送りでは市場日付や注文を進めない。
- 序章、毎朝三倍、彼女の冬、眠れる大きさ、雨のあと、最終話。冬は実際のSOXL前日比または期間内ドローダウンで発生し、回復の場面も実際の上昇があった場合に発生。
- `history.mjs` は8つの公式発表を日常の会話に脚色。公開日とゲームで見せる市場日を分け、引け後決算は翌営業日から登場。
- `friends-daily.json` はNVDA・AMD・INTC・AVGOの4,149営業日の実際の終値前日比。`import_friends.py` で元の分割調整済み終値から計算。個別企業の株価をSOXLの値動きから推定しない。
- 4社を半導体の友人に見立てる。歴代構成銘柄・比率・寄与の再現をうたわず、手紙は株価ベースの創作と明記。
- エスピーさんとSOXSちゃんは原作の関係を活用。S&P500がいつも2%しか動かない、SOXSがSOXLと厳密な逆数になる、といった設定にはしない。
- 「じっとしていれば必ず減価する」「将来必ず戻る」は採用しない。日次複利・値動きの経路で結果が変わることを会話に含める。
- 「眠れる大きさ」の選択は自動売買しない。売却・保有ゼロで関係値を下げない。この考えを共有し関係を育てれば、運用損益と独立した恋愛のTRUE ENDへ到達できる。
- 初版のセーブは移行対応。市場データの識別子を維持し、資産・進行日・親密度を保持。未読ページ・ログ・CGの整合性を読み込み時に検証。
- 読んだ場面と選択・返事を会話ログに記録。アルバムと「一枚絵を眺める」でCG全体を閲覧可能。

検証：`node --test soxl-game/tests/*.test.mjs`（25項目）。旧版の売買テストに、ページ送りと時間の分離、途中セーブ復元、将来情報の非表示、実データに基づく章の発火、デートとの併存、60日間の物語＋売買の通し進行を追加。

## 立ち絵で会話する版（2026-09-10）

- 通常は人物のいない背景6枚＋表情6種類の立ち絵。目ぱち・口パクをそれぞれ独立した差分画像で動かす。
- `performance.mjs` が文字送りと顔のタイミング、`actor.mjs` が画像読み込み・発話連動・一時停止を管理。相場の日付や注文はアニメーションから変更しない。
- 本人の台詞が出ている間だけ口が動く。読了・句読点・別の話者・CGでは止まる。タブ非表示・モーダル・タイトル画面では動作を停止し、復帰で文字が飛ばない。
- 1回目の操作で台詞を全文表示、次の操作で次のページへ。選択肢は全文表示後に現れる。本文クリック、全文表示ボタン、Enter/Spaceに対応。
- メニューで文字速度と表情アニメーションを変更できる。端末の動きを減らす設定では静止して全文を表示。音声は未収録。
- CGは小説の節目と心が通ったデートに限定。通常の背景を表示しただけではアルバムに追加しない。取引、親密度、途中ページ、旧アルバムを保持してセーブ移行する。
- 初版の4枚の不透明ポートレートは保管素材。現在の会話UIには使わない。
